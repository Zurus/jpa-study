# TASK-05. Полиморфный запрос по корню: все товары одним запросом

Тема: Entity Inheritance. Сложность: 5/10.

## Что делать

Добавить метод в `com.example.jpalab.service.ProductHierarchyService`:

```java
public List<BaseEntity> findAllProducts() {
    // TODO
}
```

Метод возвращает **все** товары (оба подкласса) одним запросом,
отсортированными по `id`. Элементы списка — конкретные подклассы
(`DigitalProduct` / `PhysicalProduct`), а не абстрактный корень.

## Как проверить

```bash
mvn -Dtest=com.example.jpalab.tasks.t17.TASK05Test#findAllProductsBothTypesOrderedById
```

## Критерии

- в базе 4 товара (2 цифровых, 2 физических);
- результат — 4 объекта, порядок по `id`;
- каждый объект — соответствующий конкретный подкласс.

## Подсказка

Запрос идёт по корню иерархии — Hibernate сам расширит условие
дискриминатором для всех подклассов и материализует каждый
объект в конкретный тип. `@MappedSuperclass`-корень (до TASK-03)
в JPQL использовать нельзя — сначала выполните TASK-03.
