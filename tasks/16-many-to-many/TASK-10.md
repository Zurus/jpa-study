# TASK-10. Полная синхронизация связей продукта с тегами

Тема: @ManyToMany. Сложность: 10/10.

## Что делать

Добавить метод в `com.example.jpalab.service.ProductTagService`:

```java
public void syncProductTags(Long productId, Set<Tag> newTags) {
    // TODO
}
```

Метод приводит связи продукта к точному совпадению с переданным
набором: связи, которых нет в `newTags`, удаляются; связи из
`newTags`, которых ещё не было, добавляются. После вызова в
`product_tag_link` у продукта остаются **ровно** строки для
`newTags`.

## Как проверить

```bash
mvn -Dtest=com.example.jpalab.tasks.t16.TASK10Test#syncProductTagsReplacesWholeLinkSet
```

## Критерии

- после sync с набором из двух тегов: старые, не входящие в набор,
  связи удалены, новые добавлены, строк ровно |newTags|;
- повторный sync с тем же набором ничего не меняет (идемпотентность);
- sync с пустым набором обрывает все связи продукта.

## Подсказка

«Просто добавить недостающие» недостаточно — старые строки должны
исчезнуть. Классический паттерн полной замены коллекции:
очистить коллекцию владельца и записать новую целиком; при
flush Hibernate сам снимет старые строки и вставит новые.
