# TASK-08. Продукты, имеющие общий с данным продукт тег

Тема: @ManyToMany. Сложность: 8/10.

## Что делать

Добавить метод в `com.example.jpalab.service.ProductTagService`:

```java
public List<Product> findProductsSharingTagWith(Long productId) {
    // TODO
}
```

Метод возвращает продукты, у которых есть хотя бы один тег, общий с
продуктом `productId`. Сам заданный продукт в результат **не входит**.
Продукт, общий по нескольким тегам, возвращается один раз.

## Как проверить

```bash
mvn -Dtest=com.example.jpalab.tasks.t16.TASK08Test#findProductsSharingTagWithExcludesSelf
```

## Критерии

- результат содержит всех, у кого есть общий тег, и только их;
- сам `productId` в результате нет;
- продукт с двумя общими тегами — один раз (без дублей);
- у продукта без общих тегов — пустой список.

## Подсказка

Можно выразить одним запросом: найти теги заданного продукта
(подзапрос по `productTags`) и выбрать продукты, чьи `productTags`
попадают в этот набор. Не забудьте `distinct` (иначе дубли по
каждому общему тегу) и исключить сам продукт.
