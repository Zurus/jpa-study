## Критерий приёмки
- продукт возвращается, если совпал ЛЮБОЙ тег из списка;
- продукт с двумя совпадающими тегами возвращается один раз;
- пустой список и полностью неизвестные теги — пустой `Set`.

## Подсказка (без решения)
Один `join` по `tags` + `in :tags` даёт union автоматически;
защита от пустого списка — до построения запроса.
