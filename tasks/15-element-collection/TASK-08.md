# Тема 15, задание 08

Тема: Элементные коллекции (@ElementCollection)
Сложность: 8

## Что нужно сделать
Добавить в `ProductElementCollectionService` метод:

```java
public void syncTags(Long productId, Set<String> newTags) {
    // TODO: привести Product.tags продукта в точное соответствие переданному набору
}
```

После вызова в `product_tags` у продукта остаются ровно элементы
`newTags`: старые, которых нет в наборе, — удалены, новые — добавлены.
Передача пустого набора очищает коллекцию.

Важно: «просто добавить элементы набора» не подходит — старые строки
останутся, и тест будет красным.

## Как проверить задание
```bash
mvn -Dtest=com.example.jpalab.tasks.t15.TASK08Test#syncTagsReplacesWholeSet
```

## Критерий приёмки
- после синхронизации в таблице ровно элементы переданного набора (ни больше, ни меньше);
- старые теги, отсутствующие в наборе, удалены;
- пустой набор оставляет ноль строк.

## Подсказка (без решения)
Hibernate сам считает diff управляемого `Set` между старым и новым
состоянием — подумайте, как привести управляемую коллекцию к целевому
набору одной-двумя операциями.
