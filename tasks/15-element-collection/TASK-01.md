# Тема 15, задание 01

Тема: Элементные коллекции (@ElementCollection)
Сложность: 1

## Что нужно сделать
Добавить в `ProductElementCollectionService` метод:

```java
public void addTag(Long productId, String tag) {
    // TODO: загрузить продукт по id и добавить тег в Set-коллекцию Product.tags
}
```

Тег должен оказаться в таблице `product_tags` (одна строка на тег).
Повторное добавление того же тега дублировать строку не должно
(это Set — элементы уникальны).

## Как проверить задание
```bash
mvn -Dtest=com.example.jpalab.tasks.t15.TASK01Test#addTagStoresRowAndIgnoresDuplicate
```

## Критерий приёмки
- после вызова метода в `product_tags` появляется строка с этим тегом;
- разные теги — разные строки;
- повторное добавление одного тега строку не дублирует.

## Подсказка (без решения)
Загрузите owner через `EntityManager`, измените управляемую коллекцию
`Product.tags` и зафиксируйте состояние. Разберитесь, почему Hibernate
сам не создаёт дубль при повторном `add`.
