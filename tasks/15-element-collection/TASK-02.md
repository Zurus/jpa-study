# Тема 15, задание 02

Тема: Элементные коллекции (@ElementCollection)
Сложность: 2

## Что нужно сделать
Добавить в `ProductElementCollectionService` метод:

```java
public void removeTag(Long productId, String tag) {
    // TODO: загрузить продукт по id и удалить один тег из Product.tags
}
```

Исчезает ровно строка этого тега; остальные элементы коллекции
не трогаются. Удаление отсутствующего тега — безопасный no-op
(без исключений и без побочных эффектов).

## Как проверить задание
```bash
mvn -Dtest=com.example.jpalab.tasks.t15.TASK02Test#removeTagDeletesRowOnly
```

## Критерий приёмки
- строка удалённого тега исчезает из `product_tags`;
- остальные теги продукта остаются;
- удаление несуществующего тега не ломает коллекцию и не бросает исключение.

## Подсказка (без решения)
Это прямое зеркало `remove` на управляемом `Set`: Hibernate отслеживает
отсутствие элемента после flush.
