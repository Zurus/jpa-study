# Задание 10. Порядок параметров: два параметра одного типа
- Тема: Derived queries (вывод запроса из имени метода)
- Difficulty: 10
- Что нужно сделать: Добавьте в `ProductRepository` метод derived query: товары, чья цена строго больше нижнего значения И меньше или равна верхнему (два параметра `BigDecimal`). Тест создан заранее (TASK10Test): он доказывает (а) граничную семантику — нижняя граница исключена, верхняя включена; (б) порядок параметров определяется ПОРЯДКОМ УСЛОВИЙ В ИМЕНИ МЕТОДА, и при «перепутанных» аргументах вызов компилируется, но молча возвращает другой (пустой) результат.
- Стартовый код:
```java
public interface ProductRepository extends JpaRepository<Product, Long> {
    // метод должен иметь точно такую сигнатуру:
    // price > lowerPrice AND price <= upperPrice (оба BigDecimal)
    List<Product> findByPriceGreaterThanAndPriceLessThanEqual(
            BigDecimal lowerPrice, BigDecimal upperPrice);
}
```
- Тест для проверки:
```bash
mvn -Dtest=com.example.jpalab.tasks.t01.TASK10Test#parameterOrderFollowsMethodName
```
- Критерий приёмки: Тест: вызов (200, 400) возвращает товары с ценами 300 и 400 (граница 200 исключена, 400 включена); вызов (400, 200) возвращает ПУСТО — компилятор не может поймать перестановку аргументов одного типа, значит смысл запроса несёт имя метода; в SQL-логе видны `> ?` и `<= ?` в порядке, соответствующем имени.
- Подсказка (не решение): порядок ключевых слов в имени метода = порядок параметров в сигнатуре = порядок условий в WHERE.
