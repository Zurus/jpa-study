# Задание 02. Поиск без учёта регистра (IgnoreCase)
- Тема: Derived queries (вывод запроса из имени метода)
- Difficulty: 2
- Что нужно сделать: Добавьте в `ProductRepository` метод derived query, находящий товар по точному имени без учёта регистра. Тест создан заранее (TASK02Test): он создаёт товар с именем в смешанном регистре и находит его, передавая имя в нижнем и верхнем регистрах.
- Стартовый код:
```java
public interface ProductRepository extends JpaRepository<Product, Long> {
    // метод должен иметь точно такую сигнатуру:
    List<Product> findByNameIgnoreCase(String name);
}
```
- Тест для проверки:
```bash
mvn -Dtest=com.example.jpalab.tasks.t01.TASK02Test#findByNameIgnoreCaseIsCaseInsensitive
```
- Критерий приёмки: Тест: оба варианта запроса (нижний и верхний регистр) возвращают созданный товар; запрос несуществующим именем возвращает пустой список. В SQL-логе видно применение функции UPPER (или эквивалентного сравнения) к имени.
- Подсказка (не решение): нужное ключевое слово добавляется к имени свойства в названии метода.
