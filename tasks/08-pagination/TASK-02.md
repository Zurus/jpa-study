# Задание 02. Sort внутри Pageable
- Тема: Пагинация (Page / Slice / Pageable / Sort)
- Difficulty: 2
- Что нужно сделать: Тест создан заранее (TASK02Test): 5 товаров с разными ценами. Первая страница запрашивается с `Sort.by("price")` по возрастанию, затем по убыванию, затем — вторая страница в том же порядке. Доказывается, что сортировка применяется к СТРАНИЦЕ и задаётся из вызывающего кода, а не в SQL метода. Методы в репозиторий добавлять не нужно.
- Стартовый код:
```java
// Тест создан заранее: com.example.jpalab.tasks.t08.TASK02Test
// Ключевые вызовы (один и тот же метод репозитория):
//   PageRequest.of(0, 3, Sort.by("price"))            -> цены [10, 30, 50]
//   PageRequest.of(0, 3, Sort.by("price", DESC))      -> цены [90, 70, 50]
//   PageRequest.of(1, 3, Sort.by("price"))            -> цены [70, 90]
```
- Тест для проверки:
```bash
mvn -Dtest=com.example.jpalab.tasks.t08.TASK02Test#sortIsPassedByCallerNotHardcoded
```
- Критерий приёмки: Тест: обе страницы отсортированы в нужном направлении; вторая страница продолжает тот же глобальный порядок (не пересортировку «внутри хвоста»); в SQL-логе `order by price asc` / `order by price desc` меняется между вызовами при том же методе репозитория; в комментарии: Sort — «данные», а не «код» — метод один, порядок разный.
- Подсказка (не решение): `PageRequest.of(page, size, Sort)` — сортировка едет вместе с пагинацией в одном объекте.
